# Sample logos

`make_samples.py` draws the three test logos: a solid circle with specks, a letter A with a hole, and a star plus a separate bar.

`out/<name>/out.dst` and `preview.png` were produced with `--test-run-values`, meaning the stand-in `TEST_RUN_OVERRIDES` in `config.py`, **not chosen product values**. They exist to check the code. Only sew them as a code check.
