This file only documents the format. Files whose name starts with "_" are never shown on the
site. To publish a post, add a new file next to this one, for example `my-post.md`: its address
becomes /blog/my-post.

Frontmatter (between the two `---` lines) needs a `title` and a `date` (YYYY-MM-DD, used to sort
newest first); `summary` is optional.

## What the Markdown can contain

- Headings with `#`, `##` or `###`
- Paragraphs, **bold**, *italic* and `code`
- Lists with `-` or `1.`
- Quotes with `>`
- Code blocks between three backticks
- Links like [this](https://example.com) or [this](/upload): only http(s) addresses and paths on this site

Raw HTML is shown as text, not run.
